# 3.5.5 — release and migration notes

## Why a patch version

It fixes two Windows installer failures and adds no surface. The MCP tools, HTTP routes, CLI,
managed header, output format `2` and every response field are unchanged.

## What changes

- **One-line install and update work in Windows PowerShell.** The Python preflight no longer
  passes double quotes to Python, which Windows PowerShell 5.1 mangled. Before this release the
  documented `powershell -ExecutionPolicy Bypass -c "irm ... | iex"` command stopped with
  `PYTHON_UNAVAILABLE` even with a supported Python installed; running it from PowerShell 7
  (`pwsh`) was the only way through.
- **Existing folder grants are kept.** The installer checks each registered folder with
  `icacls` before granting the `NT SERVICE\SQLContextPack` account Modify access. A folder that
  already grants it inheritable Modify or Full access is left unchanged, so an update no longer
  needs Administrator rights just to repeat a grant on a folder owned by Administrators. A
  folder without the grant is still granted, and still needs an owner who may change its
  permissions.

## Not changed

- `sqlctx doctor update` still needs install provenance or `--source <release-checkout>`. A
  Claude Code plugin installed from a local marketplace records none; use the one-line update
  on such a machine.
- `sqlctx doctor check` still reports `PLUGIN_VERSION_UNVERIFIED` for a Claude Code plugin
  installed from its native marketplace; `claude plugin list` shows its version.

## Migration

None. Run the one-line update, or `sqlctx doctor update --host <host> --version 3.5.5` where
install provenance exists, then confirm package, plugin and service versions with
`sqlctx doctor check --host <host>`.
